# 6FORM — лендинг

Одностраничник для 6Form: мягкие настенные изголовья на заказ.

## Стек

Чистый HTML / CSS / JS без фреймворков и сборки. GSAP + ScrollTrigger с CDN для анимаций.
Открывается двойным кликом по `index.html`.

```
index.html        разметка всех секций
css/style.css     стили и адаптив
js/main.js        конфигуратор, форма, модалки, анимации
img/              фотографии (см. NOTES.md)
NOTES.md          что заглушка, какие фото нужны и в каком формате
```

## Секции

Первый экран → коллекция Six Forms → ткани → комплектация → интерьеры и галерея →
качество и детали → размеры и как заказать → подбор с формой заявки → преимущества →
FAQ → шоурум → футер.

## Что нужно доделать перед запуском

- Заменить временные фотографии на свои (все имена файлов и пропорции — в `NOTES.md`).
- Подключить отправку заявки: сейчас она пишется в консоль браузера, точка входа помечена в `js/main.js`.
- Подставить реальные цены, контакты, адреса шоурумов и политику конфиденциальности.

Подробности — в [NOTES.md](NOTES.md).
