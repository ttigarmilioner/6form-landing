# 6FORM — прототип, проход 2

Чистый HTML/CSS/JS + GSAP с CDN. Сборки нет — открывается двойным кликом по `index.html`.

```
index.html
css/style.css
js/main.js
img/            ← сюда кладём свои фотографии
```

## Как подставить свои фотографии

Каждая картинка на сайте сначала ищется в папке `img/`. Если файла нет — временно подтягивается
фото с ylsedesign.se (только чтобы показать композицию). **Положили свой файл с нужным именем — он
подхватился сам, править код не нужно.**

| Файл | Что это | Пропорции | Мин. размер |
|---|---|---|---|
| `img/hero.jpg` | первый экран, горизонталь | 16:9 | 2400×1350 |
| `img/forms/form-01.jpg` … `form-06.jpg` | шесть форм | 4:3 | 1200×900 |
| `img/fabrics/1.jpg` | крупная фактура ткани, вертикаль | 3:4 | 1200×1600 |
| `img/fabrics/2.jpg`, `3.jpg` | ткани, горизонталь | 16:11 | 1200×825 |
| `img/sets/head.jpg`, `base.jpg` | комплектации | 4:3 | 1400×1050 |
| `img/interiors/wide.jpg` | широкий блок «одна форма — разные интерьеры» | 21:9 | 2400×1030 |
| `img/interiors/1.jpg` … `4.jpg` | галерея интерьеров, вертикаль | 3:4 | 1200×1600 |
| `img/details/1.jpg`, `2.jpg` | крупные детали: шов, кант, фактура | 3:4 | 1200×1600 |
| `img/showroom.jpg` | шоурум | 4:3 | 1400×1050 |

Формат — JPEG (или WebP с тем же именем и расширением в коде), качество 80–85, вес до ~400 КБ.
Съёмка: дневной рассеянный свет, спокойный фон, изголовье — главный объект в кадре.

Для карточек форм лучше всего работает одинаковый кадр: одна и та же стена, один свет, одно
положение камеры, меняется только форма. Тогда шесть карточек читаются как коллекция.
Пока фото нет — в карточке остаётся SVG-силуэт, и это выглядит нормально.

## Что сделано в этом проходе

1. Первый экран: подзаголовок, две кнопки (расчёт + переход к формам), три факта (от 60 000 ₽, 300+ оттенков, 2 года), нижняя полоса.
2. Формы: сетка 3×2 вместо шести мелких иконок, крупные плитки, силуэт заменяется фотографией автоматически.
3. Ткани: крупный кадр + два малых, подписи, лента образцов оттенков.
4. Комплектация: две большие карточки с фото, характеристиками и ценой.
5. Заменено фото в блоке интерьеров, которое не грузилось.
6. Добавлен чекбокс согласия — без него заявка не отправляется.
7. Превью в конфигураторе: масштаб работает на всех размерах от 90 до 210 см, при выборе «изголовье + основание» под изголовьем появляется основание.
8. Иконки преимуществ перерисованы линейными SVG.
9. Базовый кегль 16px, скругление 4px на кнопках, полях и карточках.
10. Бургер-меню включается с 900px, закрывается по клику и по Esc.
11. Новый блок «Качество / всё дело в деталях» — крупные детальные фото, как просила заказчица в аудио.

## Проход 3

- Блок «Всё дело в деталях» пересобран: крупный вертикальный кадр + квадратный кадр внахлёст со сдвигом
  и подписью, справа — нумерованный список по хайрлайнам и кнопка. Фон секции чуть темнее соседних,
  чтобы блок читался отдельно.
- Превью в конфигураторе теперь одна SVG-сцена: изголовье + матрас + основание на ножках в общей системе
  координат, поэтому ничего не разъезжается. «Только изголовье» — изголовье опускается к линии пола,
  кровать плавно исчезает; «изголовье + основание» — поднимается и встаёт на кровать.
- Маска телефона `+7-(999)-999-9999` во всех полях типа tel (заявка и запись в шоурум).
  Понимает ввод через 8 и вставку номера из буфера в любом формате.

## Что остаётся заглушкой

- **Все фотографии** — временные, с чужого сайта. Запускать с ними нельзя.
- **Отправка заявки** — пишется в консоль браузера (`js/main.js`, комментарий «сюда подключим»). Telegram/почта/CRM подключаются в одном месте.
- **Цены** — «от 60 000 ₽» за изголовье; за комплект с основанием стоит «цена по запросу», нужна цифра.
- **Адреса партнёрских шоурумов** — «уточняется».
- **Запись в шоурум** — форма без бэкенда, реальный календарь со слотами подключим отдельным сервисом.
- **Телефон, почта, соцсети, политика** — плейсхолдеры из макета.
- **Оттенки тканей** — восемь условных кружков, лучше заменить на фото фактуры.
